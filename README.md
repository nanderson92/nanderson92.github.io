# Nathan Anderson Portfolio — Cyber City Dark Theme

This is a GitHub Pages / Jekyll portfolio built for a professional research + process engineering identity.

## Install

1. Rename your repository to `nanderson92.github.io` if you want the clean root URL:
   `https://nanderson92.github.io/`
2. Copy everything in this folder into the repository root.
3. Replace `assets/files/Nathan_Anderson_Resume.pdf` with your real resume.
4. Commit and push to `main`.
5. In GitHub: Settings → Pages → Deploy from a branch → `main` → `/root`.

## Files to edit first

- `_config.yml`: name, email, LinkedIn, GitHub
- `index.html`: homepage hero and current work
- `portfolio/index.md`: project cards
- `projects/micromodular-deposition/index.md`: main research project
- `resume/index.md`: resume sections
- `assets/css/style.css`: visual theme

## Design notes

The layout uses a fixed left navigation rail, a large editorial hero, social links, a mission/about section, portfolio cards, and a footer-link structure. The background is a custom vector cyber-city skyline in `assets/images/cyber-city.svg`, not an externally hosted image.
