SIGNATURE CASE STUDY

Micromodular Electronics Deposition

Substrate-controlled process windows for printed-electronics assembly.

I use this project as the clearest example of how I think as a process engineer: define the physical bottleneck, isolate controllable boundary conditions, convert visual behavior into metrics, and translate the result into manufacturing selection criteria.

Problem Suspended microdevices can crowd, raft, pin, and accumulate near the droplet edge during spreading, drying, and imbibition. Method Compare substrate/backing conditions using top-view and side-view microscopy, then extract contact-line dynamics, deposition density, and edge/center uniformity metrics. Output A process-development case study connecting droplet transport, substrate design, image analysis, and scalable micromodular electronics assembly.
