<section class="artifact-panel setup-panel"><h2>The setup</h2><p>Growth conditions become useful only when they can be connected to measurable film response. The case file frames deposition variables against characterization readouts without overclaiming what one tool can prove.</p></section>
<section class="insight-block dark-section"><p>Characterization is only useful when each readout answers a specific process question and each limitation is named.</p></section>
<section class="next-iteration-callout early-next"><h2>What I’d do next</h2><p>Define a small characterization control plan for each deposition change: one morphology check, one structure/composition check, and one pass/fail criterion. The decision is which film response justifies changing the growth condition.</p></section>
